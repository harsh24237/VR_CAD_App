# VR CAD App for Meta Quest 2

Open this directory with Unity **2022.3.44f1**. The application scene is
`Assets/Scenes/SampleScene.unity`.

For hardware configuration, separate Quest Link / standalone builds, installation,
and the five headset acceptance checks, see [Quest 2 baseline](Docs/Quest2-Baseline.md).
Actual results and remaining blockers are recorded in
[baseline results](Docs/Quest2-Baseline-Results.md).

The baseline enables hardware XR and disables automatic XR Device Simulator startup.
Source changes import into this project in Unity; Android changes require rebuilding
and reinstalling the APK.
